## Overview

Ennismore is a hospitality group that builds lifestyle hotels and restaurants with strong personalities. Their portfolio includes The Hoxton, Mama Shelter and Mondrian. Each new restaurant needed a website that gave customers the essentials: food and drinks menus, opening hours, booking feature while feeling like an extension of the restaurant itself. They also wanted the websites to feel part of the same group while each keeping its own identity.

<Figure src={overviewPatatino} alt="Patatino restaurant interior" caption="Patatino restaurant in Edinburgh" />

## System Thinking

Every restaurant needed the same core information. So to save time, I built a modular design system: reusable components like headers, hero sections, menus, events, timetables, address blocks and footers, each adaptable to a different brand. The components stayed constant across all five sites, with variants added only where a restaurant needed something different.

## Applying the brands

Once the structure was agreed, I designed the five websites, following each brand's guidelines. A few elements had to be reworked to fit the web (a couple of the palettes were built for print and didn't pass contrast checks). Every website shared the same structure but each kept its own personality.
